# 0xB0DHI landing page

One-page illustrated link site for GitHub Pages. It needs no build step, framework, API key, or paid hosting.

## Publish on GitHub Pages

This repository contains the complete page at its root, including the `assets` folder. In **Settings → Pages**, choose **Deploy from a branch**, `main`, and `/ (root)`. Once GitHub Pages is enabled and deployment finishes, the site URL is `https://0xb0dhi.github.io/landingpage/`.

The page uses the supplied GitHub and Steam URLs. Its Discord button copies the supplied username, `0xb0dhi`.

The painting and avatar are local assets. Subtle star and parallax effects use CSS and JavaScript, with a still version for visitors who prefer reduced motion. There are no external libraries or fonts.
